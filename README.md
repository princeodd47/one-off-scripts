# one-off-scripts
Scripts which are needed but may not be reusable.

- [`windows/vpn-lan-access`](windows/vpn-lan-access) - lets LAN traffic through ProtonVPN's Windows kill switch while the VPN stays connected.
- [`windows/claude-code-statusline`](windows/claude-code-statusline) - Claude Code status line showing model, cwd, git branch, and context usage.
- [`linux/jellyfin-media-center`](linux/jellyfin-media-center) - rootless Podman/Quadlet Jellyfin setup on a spare laptop with a directly-attached USB drive.
